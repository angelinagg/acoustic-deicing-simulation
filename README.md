# ✈️ Acoustic Smart Skin: Ice Shedding Energy Simulation

Research and simulation project on ultrasonic ice shedding for aircraft wings.

# 📊 Results & Graph
This Python simulation compares traditional thermal de-icing (melting) vs. the proposed **Acoustic Smart Skin (40 kHz Ultrasonic Resonance)** system.

# 💡 Key Findings
- **Thermal System:** Requires high energy (~10^4 - 10^5 Joules) to melt ice.
- **Acoustic Smart Skin:** Requires minimal energy (~10^2 Joules) by disrupting ice adhesion.
- **Efficiency:** Ultrasonic method is **up to 1000x more energy-efficient**.
